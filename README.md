# মেট্রো যাত্রী (Metro Jatri)

ঢাকা মেট্রো রেলের যাত্রীদের জন্য Flutter অ্যাপ (Android, iPhone, ওয়েব)।

- **কোন স্টেশনে আছেন:** ফোনের GPS লাইনের ওপর প্রজেক্ট করে স্টেশন বা দুই স্টেশনের মাঝের অবস্থান দেখায়
- **গতি (কিমি/ঘণ্টা)** এবং পরের স্টেশন কত মিনিট দূরে
- **পরের মেট্রো কত মিনিট পর:** আনুমানিক সময়সূচি থেকে হিসাব
- **ডেমো মোড:** মেট্রোতে না বসেও পরীক্ষা করা যায়
- **লাইনসমূহ:** MRT-6 চালু, বাকি লাইন "আসছে" হিসেবে

## চালানো

```sh
flutter pub get
flutter run            # সংযুক্ত ফোন বা এমুলেটরে
flutter test
```

## কোড

| ফাইল | কাজ |
|---|---|
| `lib/data/lines.dart` | লাইন ও স্টেশনের তথ্য (স্থানাঙ্ক আনুমানিক) |
| `lib/logic/geo.dart` | GPS পয়েন্টকে লাইনের ওপর প্রজেক্ট করা |
| `lib/logic/tracker.dart` | GPS/ডেমো থেকে স্টেশন, দিক, গতি |
| `lib/logic/schedule.dart` | পরের ট্রেনের আনুমানিক সময় |
| `lib/screens/` | UI |

## সীমাবদ্ধতা

স্টেশনের স্থানাঙ্ক ও সময়সূচি (পিকে ৮ মিনিট, অন্য সময় ১০ মিনিট, শুক্রবার বিকাল ৩টা থেকে) আনুমানিক। DMTCL-এর অফিসিয়াল ডেটা পেলে `lines.dart` ও `ScheduleConfig` আপডেট করতে হবে।
